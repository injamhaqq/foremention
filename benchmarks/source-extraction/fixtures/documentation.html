Source X-Ray methodology

Source X-Ray separates crawler observations from human review. Reachability, status code, redirects, title, and bounded text fingerprints are objective page observations.

Methodology version is part of comparability. A later collection should not be compared as movement when the exact question, provider, model, or methodology changed.

Inspection never turns page text into a verified customer claim. Review decisions remain explicit and attributable.
