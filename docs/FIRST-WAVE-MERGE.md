# First-wave merge record

This rebuild reconciles the supplied Foremention artifacts with the current product-first direction. It preserves useful interface, evidence, and data architecture while removing earlier agency/service positioning and superseded identity directions.

## Current canonical identity

- Category: **Recommendation Intelligence**
- Descriptor: **Recommendation intelligence for B2B software.**
- Core expression: **Register. Prove. Prepare.**
- Primary object: **Recommendation Record**
- Product shell: near-black `#0D0F0E`, graphite `#151817`, registered green `#176347`
- Fonts: Newsreader, Inter, IBM Plex Mono
- Canonical assets: `public/brand/foremention-logo-white.svg` and `public/brand/foremention-mark-white.svg`
- Voice: evidence-led, plain language, no hype, no invented proof, and no guaranteed outcomes

The old Meridian OS / Source Eclipse / copper-cobalt directions are superseded and must not be revived. Source X-Ray is also retired as a standalone product object; evidence inspection lives inside the Recommendation Record.

## What was kept

- Public and signed-in product UI, canonical identity assets, design tokens, and restrained motion language
- Recommendation Record, contained evidence inspection, Source Map evidence review, Recommendation Graph, provider-adapter boundary, prompt freezing, and raw evidence
- Loading, empty, error, partial-failure, and fictional-demo states

- Specialist tools such as competitor tracking, Resolution Center, Outcome Ledger, Vendor Passport, Intelligence Loop, Agent Control Plane, Decision Lab, and Evidence Vault, surfaced contextually from the five canonical signed-in objects

## What was removed or superseded

- Placement packages, audits, retainers, monitoring downsells, and white-label agency delivery
- “We do the work for you” and other service-led positioning
- Superseded prices and offer ladders
- Superseded Meridian OS / Source Eclipse / copper-cobalt identity directions
- Standalone Source X-Ray navigation
- Unverified statistics, placeholder customers, fake proof, and guaranteed outcomes
- Fabricated reviews, undisclosed promotion, sockpuppets, or paid editorial presented as independent evidence

## Current commercial model

Foremention is validating founder-led design-partner terms with real teams. Core and Signal are concrete software package scopes, but the repository does not fabricate public dollar pricing. Intelligence remains sales-led/custom-scoped.

Creating a design-partner/private-beta workspace does not charge a card or silently activate a paid entitlement. Self-serve recurring Core/Signal Checkout is implemented with Stripe but remains fail-closed unless real Stripe credentials, a webhook secret, and approved package Price IDs are configured. Entitlements are granted only from a verified asynchronous billing webhook, never from a browser success redirect. Intelligence remains custom-scoped rather than self-serve.
