# Chat08 operating templates

Header-only CSVs. They intentionally contain **no rows**: Chat08 has no verified prospects, interviews, offers, time entries, reviews or consents, and must not seed examples that could be mistaken for evidence. When used, each row must cite its source (URL, Paddle transaction ID, signed document reference, or support ticket ID) and be mirrored into the existing service-only tables listed in `../customer-operations-playbook.md`. Never store these files with real personal data in the public repository; keep filled copies in the private operator system.
