# Production gap analysis

Date: 2026-07-24

## Preserved strengths

- Self-serve Source Map, Source X-Ray, Recommendation Graph, evidence, run history, and action workspace
- Deterministic fictional demo with no provider calls or credentials
- Supabase authentication, multi-tenant schema, RLS, provider adapters, and Inngest job boundary
- Cloudflare/Sites-compatible Vinext runtime and D1 public-intake persistence
- Honest outcome boundaries and separation of observed evidence from product assessment

## Implemented in this rebuild

- Product-first public copy and recurring software plans
- Public Product, Source Map, Sample Report, Pricing, Methodology, Honesty, comparison, privacy, terms, contact, recovery, and resilient framework routes
- Customer-operated onboarding, prompts, source records, opportunities, evidence, analytics, and settings
- Interactive recommendation journey with a keyboard-accessible static alternative
- Project-owned Open Graph image, sitemap, robots configuration, brand assets, focus states, and reduced-motion support
- Responsive route inventory, seeded demo access, and production documentation

## External gates still open

- Production Supabase migrations and RLS isolation have not been proven against the hosted project
- Long-lived refresh-token rotation and session-revocation tests are still required
- Live provider adapters need credentials, model approval, evaluation fixtures, budgets, and failure testing
- Hosted Inngest execution needs event/signing keys and a confirmed persisted run
- Payment checkout and verified webhook-driven entitlements are not yet connected
- Legal entity, jurisdiction, terms, privacy, retention, subprocessors, and incident process need approval
- Error monitoring, analytics, backups, restore tests, accessibility review, and real-device QA remain launch gates

Do not describe any open gate as production-verified until its evidence is recorded.
